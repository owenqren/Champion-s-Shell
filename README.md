# Champion's Shell

A Hollow Knight mod that adds a new charm, **Champion's Shell**. It is inspired by the Champion's Tunic in *Breath of the Wild*: while it is equipped, you can see the boss's health.

> Status: early development. Nothing is playable yet.

## Planned features

- **Boss health bar.** While the charm is equipped, a health bar shows the current boss's remaining HP. It works in the main game and in Godhome.
- **A second ability.** The charm also gives a combat bonus so it earns its notch. This is not decided yet; bonus damage against bosses and extra soul are the current ideas.
- **Easy to get.** The base charm is sold in a shop early in the game.
- **Upgrades at the Nailsmith.** Pay geo and hand over a relic, such as a Wanderer's Journal, to upgrade the charm. Each upgrade makes the second ability stronger. Lemm is unchanged; you just keep the relic instead of selling it.

## Requirements

- Hollow Knight 1.5 (built against 1.5.12620)
- [Hollow Knight Modding API](https://github.com/hk-modding/api)

## How it works

The mod changes the game while it runs, using Modding API hooks and edits to PlayMaker FSMs. It does not replace any game files or scenes.
